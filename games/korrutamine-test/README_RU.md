# Прототип игры «Звездопад умножения»

Путь для локального запуска:

`games/korrutamine-test/index.html`

## Что есть в версии 14

- вертикальное игровое поле, рассчитанное прежде всего на телефон;
- три тестовых уровня: таблицы ×2, ×5 и ×10;
- три скорости звездопада;
- звездопад вместо движущегося монстрика;
- правильный ответ отталкивает звёзды вверх;
- неправильный ответ мигает, очищается и оставляет звездопад в движении;
- автоматическая проверка ответа через 650 мс после последней цифры;
- кнопка Enter не требуется и удалена с экранной клавиатуры;
- русский и эстонский интерфейс;
- сохранение открытых уровней в браузере.

Это отдельный тестовый прототип. На главную страницу сайта он пока не выведен.
