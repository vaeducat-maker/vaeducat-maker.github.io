# Прототип первой главы «Один и два»

Путь для локального запуска:

`games/korrutamine-test/index.html`

## Что есть в версии 17

- интерактивный вводный экран вместо свободного выбора сложности;
- карта из 15 последовательно открывающихся уровней;
- совместное начало с числами 1 и 2, с основной нагрузкой на умножение на 2;
- карточки с четырьмя ответами на уровнях 1 и 11;
- самостоятельный ввод без Enter со 2-го уровня;
- десять уровней умножения, четыре уровня деления и смешанный финальный уровень;
- ровно 15 правильных примеров на каждом уровне;
- чистая попытка 15/15 как обязательное условие прохождения;
- возвращение ошибочного примера через несколько заданий;
- первые учебные уровни без таймера и постепенное подключение звездопада;
- сохранение открытых и пройденных уровней в браузере;
- аккуратная мобильная компоновка и отдельная двухколоночная компоновка для компьютера.

Тестовый интерфейс пока оставлен на русском языке. Ссылка на главу добавлена на главную страницу сайта.
