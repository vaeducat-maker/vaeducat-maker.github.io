## Исходный проект

В `src` находятся шаблон страницы, стили и игровой код. Иллюстрации входят в `assets`. Для проверки математики выполните `node tests/independent-math-review.cjs`. Для повторной сборки автономного HTML выполните `node tools/build.mjs` в Node.js 20 или новее. Результат появится в `release`.

Браузерный тест находится в `tests/journey.html`. Он проходит все задания с экранной клавиатуры, открывает бинокль и каждую открытку, а затем сверяет финальную карту. Для этого теста откройте страницу через локальный веб-сервер из корня проекта. Результаты проверок приведены в `QA_REPORT.md`.

## Изменения v45

- Кнопка получения открытки после Mäekuru стала надёжнее: открытка открывается касанием изображения или большой кнопки «VÕTA POSTKAART».
- Вместо двух одинаковых галерей показывается единая коллекция 9 открыток; полученные можно открыть.
- Кнопка следующего маршрута ориентируется на фактически собранные открытки (например, при 6/9 ведёт в Vanalinn).
- Машина видна целиком на проблемной дороге к маяку, при этом второй автомобиль поверх кадра не появляется.
- Движение и промежуточные анимации ускорены на 20%; время на математический ответ не уменьшено.
- Сайт EDUKASS не менялся: эта версия хранится в отдельной ветке GitHub.
