# Исправления версии 45 — 19 ноября 2026 года

1. Mäekuru → Järveäär: добавлен доступный касанием переход с изображения к открытке и видимая кнопка для продолжения; учтено зависание при нажатиях на Android.
2. Убрана дублирующая коллекция открыток: одна сетка из девяти кликабельных наград, закрытые неактивны.
3. Исправлена навигация: следующая станция определяется по фактическому прогрессу 0–9/9, не по устаревшему экрану маршрута.
4. Возвращён целиком видимый автомобиль в финальном дорожном кадре маяка, выровнен над частично нарисованной машиной во избежание дублирования.
5. Визуальная скорость движения и переходов увеличена примерно на 20% (длительности ÷1.2), время на ответ и опасность столкновения не сокращены.
6. Сохранены 9 уровней, 8 + 8×12 = 104 задания, 88 исходных иллюстраций, без публичной публикации.

# Журнал версии 44

- Первый маршрут содержит 8 заданий, а маршруты 2–9 — по 12 заданий вместо 16.
- Лестница сложности перераспределена по всей игре: десятки и сотни → первое знакомство с тысячами → уверенные тысячи → десятки тысяч → сотни тысяч → три вводных задания на округление до миллиона в самом конце.
- Новый разряд появляется сначала в двух-трёх заданиях в конце маршрута и становится основным только на следующей станции.
