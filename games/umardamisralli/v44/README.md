## Исходный проект

В `src` находятся шаблон страницы, стили и игровой код. Иллюстрации входят в `assets`. Для проверки математики выполните `node tests/independent-math-review.cjs`. Для повторной сборки автономного HTML выполните `node tools/build.mjs` в Node.js 20 или новее. Результат появится в `release`.

Браузерный тест находится в `tests/journey.html`. Он проходит все задания с экранной клавиатуры, открывает бинокль и каждую открытку, а затем сверяет финальную карту. Для этого теста откройте страницу через локальный веб-сервер из корня проекта. Результаты проверок приведены в `QA_REPORT.md`.
