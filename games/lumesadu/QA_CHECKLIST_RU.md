# LUMESADU — QA CHECKLIST v1

Статус: чек-лист скрытого прототипа.
Дата: 19.09.2026.

Цель: не допустить, чтобы визуально красивый прототип случайно стал публичным релизом без проверки механики, языка, мобильной компоновки и педагогики.

## P0 — блокирует любой публичный релиз

- [ ] В обычной ошибке неверная карточка красная.
- [ ] После неё правильная карточка явно зелёная.
- [ ] При обычной ошибке НЕТ текста Proovi uuesti!.
- [ ] После каждой ошибки появляется ровно 1 новый ряд льда.
- [ ] В каждом ледяном ряду ровно 4 кубика.
- [ ] При 5-й ошибке сначала показан правильный ответ.
- [ ] Затем добавляется последний ряд.
- [ ] Затем идёт crack / rumble / collapse.
- [ ] Только после collapse появляется Proovi uuesti!.
- [ ] Mute полностью отключает игровые звуки.
- [ ] Нет передачи конкретных ответов, ошибок или детского progress во внешнюю аналитику.
- [ ] Нет runtime AI / обязательного внешнего сервиса.
- [ ] Основной игровой экран работает без обязательного vertical scroll.
- [ ] Финальные иллюстрации оригинальные и не копируют стороннюю игру.
- [ ] Эстонские UI-строки проверены на грамматику и естественность.
- [ ] Owner visual acceptance получен.
- [ ] Отдельно решена delayed retry логика по PEDAGOGICAL_CONSTITUTION_RU.md.

## P1 — обязательно для хорошего mobile UX

Проверить минимум:
- [ ] 390×844 portrait.
- [ ] 412×915 portrait.
- [ ] 844×390 landscape.
- [ ] 1440×900 desktop.

На каждом размере:
- [ ] LUMESADU не обрезан.
- [ ] Leia õige pilt читается.
- [ ] Текущее слово читается мгновенно.
- [ ] 4 answer cards помещаются в одну строку.
- [ ] Touch targets достаточно крупные.
- [ ] Answer cards не перекрываются с системной нижней зоной.
- [ ] Safe-area сверху учтена.
- [ ] После 1–4 рядов льда ответы поднимаются, но остаются доступными.
- [ ] На 5-м ряду defeat animation не вылезает за viewport.
- [ ] Modal Pause помещается без scroll или остаётся безопасно доступным.
- [ ] Start screen кнопка ALUSTA видна сразу.

## P1 — игровой цикл

- [ ] ALUSTA создаёт новую перемешанную партию.
- [ ] На экране всегда 4 ответа.
- [ ] В вариантах ровно 1 правильный ответ.
- [ ] Две одинаковые кнопки не появляются в одном задании.
- [ ] Правильный tap блокирует повторные taps до перехода.
- [ ] Wrong tap блокирует повторные taps до завершения feedback.
- [ ] Timeout не срабатывает после уже выбранного ответа.
- [ ] Pause действительно останавливает текущий timeout.
- [ ] Jätka корректно возвращает игру.
- [ ] Alusta uuesti полностью очищает текущую ледяную стену.
- [ ] Proovi uuesti после defeat запускает чистую попытку.
- [ ] Avalehele возвращает start screen.
- [ ] Share не ломает игру при отмене системного share sheet.

## P1 — ледяная стена

- [ ] 0 ошибок = 0 рядов.
- [ ] 1 ошибка = 4 кубика.
- [ ] 2 ошибки = 8 кубиков.
- [ ] 3 ошибки = 12 кубиков.
- [ ] 4 ошибки = 16 кубиков.
- [ ] 5-я ошибка = 20 кубиков до collapse.
- [ ] Каждый ряд визуально воспринимается единым рядом.
- [ ] Рост идёт снизу вверх.
- [ ] Answer dock поднимается синхронно.
- [ ] Стена не выглядит как отдельная абстрактная шкала.

## P1 — feedback

Correct:
- [ ] Яркий зелёный.
- [ ] Видимая галочка или эквивалентный сигнал.
- [ ] Короткий позитивный звук.
- [ ] Автоматический переход.

Wrong:
- [ ] Только выбранная неверная сначала красная.
- [ ] Затем правильная зелёная.
- [ ] Green визуально сильнее и понятнее.
- [ ] Нет обвиняющей фразы.
- [ ] Нет немедленного ручного “исправь сам”.

## P1 — defeat

- [ ] 5-я ошибка не перескакивает сразу на overlay.
- [ ] Видна последняя учебная пара red → green.
- [ ] Видно появление финального ряда.
- [ ] Есть короткая screen rumble.
- [ ] Есть визуальная трещина.
- [ ] Есть audible crack при включённом звуке.
- [ ] Есть collapse.
- [ ] После этого отображается Proovi uuesti!.
- [ ] Нет Game over / Kaotasid.

## P1 — звук и accessibility

- [ ] Все события понятны при mute.
- [ ] Ошибочный звук не пугает.
- [ ] Crack не слишком громкий по отношению к остальным звукам.
- [ ] prefers-reduced-motion сохраняет смысл игры.
- [ ] Кнопки имеют accessible names.
- [ ] Основные действия доступны клавиатурой на desktop.
- [ ] Focus не теряется в недоступном слое после modal.

## P2 — содержание и методика

- [ ] Каждая картинка однозначно соответствует слову.
- [ ] lumi и lumehelves визуально не путаются.
- [ ] Distractors достаточно близки по теме, чтобы ребёнок реально читал слово.
- [ ] Нельзя пройти большинство заданий только по “совсем чужой картинке”.
- [ ] Ошибочное слово возвращается позже, а не сразу.
- [ ] Повтор не превращается в видимую историю провала.
- [ ] Rahulik даёт достаточно времени ребёнку, который читает медленно.
- [ ] Таймаут не превращает игру в стресс.
