# EDUKASS — производственный стандарт познавательных плакатов

**Статус:** УТВЕРЖДЁН владельцем · canonical для новых познавательных и соцсетевых плакатов EDUKASS.  
**Дата фиксации:** 12.11.2026.  
**Основа:** утверждённый «EDUKASS. Производственный стандарт плакатов», редакция v2, и зафиксированные эталоны серий Rahvakalender / Eesti vaatamisväärsused.  
**Граница применения:** не переделывать уже утверждённые MASTER-плакаты задним числом. Для каждой серии её LOCKED TEMPLATE и MASTER имеют приоритет как эталон конкретного выпущенного артефакта. Любой содержательный конфликт документируется и передаётся владельцу, а не устраняется догадкой.

## Цель

Производить не случайные красивые картинки, а достоверные, понятные детям и пригодные для публикации образовательные материалы. После первичной настройки серии **обычный плакат должен собираться примерно за 10–20 минут** (целевой ориентир; сложный фактчекинг может занимать больше).

**Главное правило: принятый элемент не создаётся заново.** Нельзя после исправления одной детали перегенерировать весь плакат и случайно потерять утверждённые текст, иллюстрации или компоновку.

## Обязательный конвейер (10 этапов)

1. **LOCKED TEMPLATE серии.** Один раз фиксируются A4, сетка, поля, шрифты, палитра, заголовки, блоки, рамки, нижний колонтитул, канонический маскот и допустимые адаптации. Не изобретать стиль заново для каждого выпуска.
2. **FACT PACK.** Из надёжных источников собрать только подтверждённые сведения, даты, написания и контекст. Для обычного плаката ориентир — **6–8 сильных фактов**. Зафиксировать источники и места возможных споров. Не подменять исторические обычаи универсальными утверждениями.
3. **TEXT MASTER.** Отдельно от дизайна собрать полный текст: заголовки, разделы, фразы, числовые данные и подписи. Ничего не дописывать при рисовании.
4. **Проверка 1–6 до показа владельцу.** Проверить, исправить найденное и повторно проверить затронутые пункты: (1) грамматика эстонского; (2) филология и естественность языка; (3) факты/этнография/история/география; (4) методика и возрастная понятность; (5) структура, дизайн и стандарты EDUKASS; (6) независимая критическая роль «конкурент, который хочет докопаться».
5. **VERIFIED TEXT MASTER → TEXT LOCKED.** Владельцу предъявляется **только уже проверенный** TEXT MASTER, не сырой черновик. После его команды «ТЕКСТ LOCKED» нельзя менять слова, цифры, формулировки и смысловую структуру без отдельного разрешения.
6. **Иллюстрации.** Подтверждённые факты обеспечиваются отдельными тематическими иллюстрациями; исходно **без встроенного текста и логотипа**. Принятые изображения сохраняются и не перегенерируются ради другой правки.
7. **Техническая сборка MASTER.** Собрать редактируемый макет из locked-текста, принятых иллюстраций и канонических элементов. Работа с размерами, полями, положением и отступами допустима; переписывание текста — нет.
8. **DIFF CHECK.** Пословно сверить получившийся плакат с TEXT MASTER и FACT PACK; проверить все объекты, даты, картинки, подписи, колонтитул и отсутствие самовольных вставок.
9. **MASTER LOCKED.** После команды «Фиксируем MASTER» содержание и дизайн-система заблокированы. Все дальнейшие изменения только по точному списку разрешённых исключений.
10. **Адаптации.** Сделать A4, FB/IG (обычно 4:5) и Pinterest (обычно 2:3) из того же MASTER. Разрешены технические перестановки, переносы, масштабы, безопасные поля и размеры текста. Нельзя добавлять новые факты, произвольные картинки, иные формулировки или новый дизайн.

## Визуальный канон

- Система EDUKASS: читаемый синий заголовок, ясная иерархия, аккуратные рамки/разделители, светлый фон и узнаваемая палитра серии. Точные размеры и композицию задаёт её LOCKED TEMPLATE.
- Для познавательного плаката используются **реалистичные учебные иллюстрации, не фотографии**: верные форма, цвет, масштаб, видовые признаки, местность, архитектура, эпоха и традиция. Стилизовать можно, искажать факты — нельзя.
- **Факт → визуал:** карта маршрута — достоверная схема; исторический объект — правдоподобная реконструкция; местная природа — подтверждённые виды; традиция — подтверждённый сюжет.
- Для географических схем, не являющихся настоящей масштабной картой, писать **SKEEM** и при необходимости **mitte mõõtkavas**. Не добавлять ложные координаты, масштаб или северную стрелку.
- Запрещены вымышленные памятники, здания, животные, экзотические птицы, «красивые» случайные детали, декоративные непроверенные утверждения и псевдофакты. Нет надуманного «фактического» визуала ради заполнения пустого места.
- Для новых A4-эталонов из редакции v2: снизу слева **канонический кот EDUKASS + edukass.ee**, в центре **номер страницы, если нужен**, справа — ничего лишнего. Маскот берётся из исходника, а не генерируется заново. **Никаких слоганов.** Если исторический MASTER серии уже утверждён с другим колонтитулом, сохранять именно его, не менять молча.
- Для социального формата сохранять содержание и фирменные элементы своего MASTER, без «улучшений» нового генератора. Публикации серий про Эстонию — на эстонском, если владелец не решил иначе.

## DIFF CHECK: выпуск разрешён, только если

- [ ] Текст в макете совпадает с TEXT LOCKED **слово в слово**; совпадают все даты, названия и числа.
- [ ] Все блоки присутствуют, ни один не добавлен без согласования.
- [ ] Каждая иллюстрация соответствует факту и не содержит вымышленных признаков.
- [ ] Схема не маскируется под точную карту.
- [ ] Маскот, палитра, рамки, заголовки и колонтитул взяты из принятых элементов.
- [ ] Размер и контраст текста пригодны для телефона и реальной печати A4; края не обрезаны.
- [ ] FB/IG и Pinterest проверены против одного MASTER; ни один новый факт не появился.
- [ ] Проверены итоговые изображения/экспорт, а не только исходные файлы.

Проверки и формат отчёта: **docs/POSTER_PRESENTATION_QA_CHECKLIST_RU.md**.

## Явные статусы и команды

**FACT PACK — готов → TEXT MASTER — проверен 1–6 → VERIFIED TEXT MASTER — на согласование → TEXT LOCKED → MASTER собран → DIFF CHECK: PASS → MASTER LOCKED → FB/IG / Pinterest сверены с MASTER.**

Команды владельца: «Новый плакат по стандарту EDUKASS»; «ТЕКСТ LOCKED»; «Собирай MASTER»; «DIFF CHECK»; «Фиксируем MASTER»; «Делай комплект».

**Запрещённый короткий путь:** «Сначала сгенерируем красивый плакат, потом как-нибудь исправим текст». Порядок всегда обратный: содержание → самостоятельная проверка → фиксация → сборка → diff.
