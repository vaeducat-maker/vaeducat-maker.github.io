# EDUKASS — обязательный QA / приёмка плаката и живой презентации

**Статус:** УТВЕРЖДЁН владельцем · canonical процедура QA к двум стандартам.  
**Дата:** 12.11.2026.  
**Применять вместе с:** docs/POSTER_PRODUCTION_STANDARD_RU.md и docs/LIVE_PRESENTATION_STANDARD_RU.md.

## Принцип доказуемости

Проверка — **действие с проверяемым результатом**, а не фраза «всё проверил». В каждом отчёте указываются выпуск/версия, эталон TEXT MASTER, проверенный артефакт/ссылка, дата и результаты **PASS / FAIL / NOT RUN**. Отсутствие инструмента или ручного просмотра означает **NOT RUN**, а не PASS.

**До показа владельцу TEXT MASTER обязан пройти QA 1–6.** Сырой текст не отправляется на утверждение. Владелец согласовывает смысловые акценты и подачу, а не исправляет ошибки помощника.

## QA 1–6: повторять после исправления затронутых пунктов

| № | Проверка | Что именно проверить |
|---|---|---|
| **1** | Грамматика | Правописание эстонского, падежи, согласование, пунктуация, написание названий, дат и сложных слов. |
| **2** | Филология | Естественный эстонский язык; формулировки не калькируют русский; корректны термины, народные названия, стилистика и контекст. |
| **3** | Факты и достоверность | Каждый факт подтверждён; даты, история, этнография, флора/фауна, география и обычаи не подменены догадками. Поверья обозначены как поверья, схемы — как схемы. |
| **4** | Методика для детей | Понятный возрастной уровень, отсутствие лишнего текста, поэтапность, учебная цель каждого блока/кадра, отсутствие внешних заданий, не утверждённых заказчиком. |
| **5** | Дизайн/стандарт EDUKASS | Сохранены LOCKED TEMPLATE, фирменная система, маскот/подвал, читаемость, содержательная визуализация и единство плаката с презентацией. |
| **6** | «Конкурент, который хочет докопаться» | Искать непроверенные фразы, двусмысленности, видовые/исторические ошибки, фактический визуальный обман, забытые блоки, нечитабельный мелкий текст, «исправили одно — сломали другое». |

Проверяющий не должен ограничиваться отчётом генератора; по возможности сверять с исходниками и готовой визуализацией. Найденное исправить **до предъявления**, затем повторить проверки затронутых участков.

## GATE A — до TEXT LOCKED

- [ ] Сохранён FACT PACK со ссылками или точными библиографическими данными.
- [ ] Перечень фактов соответствует теме; спорные сведения проверены или удалены.
- [ ] Весь текст в TEXT MASTER, включая подписи, даты и названия.
- [ ] QA 1–6 проведена и замечания исправлены, повторные проверки задокументированы.
- [ ] Владелец получил статус **VERIFIED TEXT MASTER — проверен 1–6**.
- [ ] Получена явная команда **ТЕКСТ LOCKED** до художественной сборки.

## GATE B — плакат после сборки: DIFF CHECK

- [ ] Каждая строка текста, число, дата, подзаголовок и подпись совпадают с TEXT LOCKED.
- [ ] Нет новых или пропущенных смысловых блоков и неподтверждённых утверждений.
- [ ] Иллюстрации проверены на тематическую и реальную достоверность; нет случайного декора.
- [ ] Картографические схемы корректно обозначены.
- [ ] Вставлены именно канонические изображения и маскот; сохранена композиция approved MASTER.
- [ ] Колонтитул, сайт, номер страницы (если требуется) и отсутствие слоганов проверены.
- [ ] Проверены не только размеры файла, но и визуальное качество на A4 и мобильном экране.
- [ ] Соцформаты 4:5 и 2:3 сравнены с A4 MASTER; все содержательные отличия отсутствуют.
- [ ] Только после PASS и одобрения владельца присвоен **MASTER LOCKED**.

## GATE C — презентация на основе плаката

- [ ] Для **каждого учебного экрана** есть запись, из каких конкретных фраз TEXT MASTER он составлен.
- [ ] Никаких новых фактов, тестов, викторин и самостоятельных обобщений без отдельного согласования.
- [ ] Все слова, даты и этнографические детали снова сверены с плакатом; выполнена QA 1–6.
- [ ] Презентация и плакат узнаются как один визуальный продукт, иллюстрации фактически корректны.
- [ ] Появление информации идёт по нажатию, а не неуправляемым автолистанием.
- [ ] Работают **вперёд, назад, перезапуск** и по возможности полноэкранный просмотр.
- [ ] Если есть пролог: он открывается раньше учебных экранов, **пропускается**, а возврат к началу воспроизводит его снова; в нём нет новых фактов.
- [ ] Проверены мышь/тап, клавиатура, узкий телефон, большая доска и доступность текста.
- [ ] Проверено **prefers-reduced-motion**: нет блокировки обучения ради эффекта.
- [ ] Проверены реальные загрузка, переходы, отсутствие ошибок и повреждённых изображений.
- [ ] Фактически проверены и записаны размеры: **390×844, 844×390, 1440×900** или объяснено, почему какой-то размер NOT RUN.
- [ ] Сравнили с утверждённым эталоном **после** всех исправлений; owner approval → **PRESENTATION MASTER LOCKED**.

## Минимальный протокол результата

- **Артефакт / тема:** ...
- **Версия / ссылка / SHA (при наличии):** ...
- **Источники истины:** FACT PACK ... / TEXT MASTER ... / MASTER-плакат ...
- **QA 1:** PASS / FAIL / NOT RUN — замечания ...
- **QA 2:** PASS / FAIL / NOT RUN — замечания ...
- **QA 3:** PASS / FAIL / NOT RUN — замечания ...
- **QA 4:** PASS / FAIL / NOT RUN — замечания ...
- **QA 5:** PASS / FAIL / NOT RUN — замечания ...
- **QA 6:** PASS / FAIL / NOT RUN — замечания ...
- **DIFF CHECK:** PASS / FAIL / NOT RUN — сравниваемые версии ...
- **Визуальная проверка A4 / соцформатов:** PASS / FAIL / NOT RUN ...
- **Проверка браузера / телефона / доски / анимации:** PASS / FAIL / NOT RUN ...
- **Что не проверено и почему:** ...
- **Требуемые исправления:** ...
- **Решение владельца:** NOT YET APPROVED / TEXT LOCKED / MASTER LOCKED / PRESENTATION MASTER LOCKED ...

**Запрет:** если есть FAIL или существенный NOT RUN, нельзя сообщать «полностью проверено», «ошибок нет» или присваивать финальный статус. Проверка после технической сборки не заменяет филологический/фактический аудит до LOCK.
