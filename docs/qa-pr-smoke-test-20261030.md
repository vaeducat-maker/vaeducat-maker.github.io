# EDUKASS — тест обязательного Quality Gate

Этот файл создан только для безопасной проверки нового процесса Pull Request.

Цель теста:
- Ветка `main` остаётся без изменений.
- GitHub запускает обязательную проверку **Approved assets, math, real browser and navigation** для PR.
- Ошибочная проверка должна блокировать слияние; успешная — разрешать его.
- Никакие игровые файлы, математические задания или сохранения детей не изменяются.

Контрольный PR можно закрыть без слияния после проверки.
