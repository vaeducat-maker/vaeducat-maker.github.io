# EDUKASS — языки и версии сохранения

## Языковая система

Текущий и единственный опубликованный язык первой главы — эстонский (`et`). Все
утверждённые строки собраны в `games/korrutamine-test/locales/et.js`.

Разделение файлов:

- `locales/et.js` — эстонские тексты и подписи;
- `i18n.js` — выбор языка, подстановка параметров и применение строк к HTML;
- `chapter-one.config.js` — ключи названий миссий и список поддерживаемых языков;
- `game.js` — обращается к текстам по ключам, не хранит эстонские фразы внутри
  игровой логики.

В HTML оставлены эстонские запасные тексты. Поэтому страница остаётся понятной,
даже если дополнительный языковой скрипт не загрузился. Базовый файл `locales/et.js`
обязателен: без него динамические строки не смогут безопасно вернуться к эстонскому.
Новый язык добавляется отдельным файлом `locales/<код>.js`; затем его `<script>`
подключается в `index.html`, а код включается в `supportedLanguages`. До публикации
проверяются загрузка базового языка, возврат к нему при ошибке, все ключи, длина
подписей, формы числительных, мобильная компоновка и произношение, если появится
голос.

Параметр `?lang=et` уже поддерживается. Если запрошенного языка нет, игра
безопасно возвращается к эстонскому.

## Сохранение прогресса

Существующие ключи браузера намеренно не переименованы:

- `edukass-chapter-one-v18` — прогресс главы;
- `edukass-sound-enabled` — выбор звука;
- `edukass-opening-seen-v28` — просмотр заставки.

Они вынесены в `chapter-one.config.js`, чтобы случайное переименование было
заметно при проверке.

Объект прогресса теперь содержит `saveVersion: 1`. Файл `progress-store.js`:

- читает старое сохранение без номера как версию 0;
- переносит его в текущую структуру без потери открытых миссий, объяснений и
  статистики примеров;
- ограничивает номер открытой миссии реальным числом миссий;
- начинает новую главу только при повреждённом или неподдерживаемом формате;
- всегда записывает номер текущей версии.

При будущем изменении структуры сначала добавляется миграция `1 → 2`, затем
увеличивается `progressSchemaVersion`. Нельзя просто менять поля сохранения или
ключ браузера: это обнулит прогресс у уже игравших детей.
