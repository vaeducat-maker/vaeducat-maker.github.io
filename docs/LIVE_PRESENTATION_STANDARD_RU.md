# EDUKASS — стандарт «живой презентации» на основе MASTER-плаката

**Статус:** УТВЕРЖДЁН владельцем · canonical для будущих интерактивных презентаций EDUKASS.  
**Дата фиксации:** 12.11.2026.  
**Первый утверждённый образец:** «RAHVAKALENDER: NOVEMBER» — 11 учебных экранов и отдельный анимированный пролог.  
**Эталон (внешний опубликованный продукт):** https://edukass-november-interaktiivne-oppetund-6o3nu8.v2.appdeploy.ai/  
**Важно:** эта ссылка — reference, **не** исходник на GitHub и не замена архиву TEXT MASTER / MASTER-плаката. Стандарт не требует менять работающий ноябрьский релиз.

## 1. Что это за продукт

**Живая презентация — не самостоятельный учебник и не новая версия содержания.** Это выразительное, последовательное, управляемое учителем **визуальное раскрытие уже утверждённого плаката**.

- **Единственный источник фактов и текста — LOCKED MASTER-плакат / TEXT MASTER соответствующего выпуска.**
- Никаких новых дат, объяснений, обычаев, определений, исторических деталей, выводов и подписей, которых нет в MASTER. Допустимо распределять утверждённые фразы по экранам и показывать их по частям **без изменения смысла**.
- Не добавлять тесты, игры, викторины или упражнения «для интерактива», если их отдельно не заказали и не утвердили.
- Плакат и презентация должны восприниматься как **один продукт:** одинаковая тема, визуальный характер, палитра, уровень иллюстраций, согласованная типографика и исходные изображения, когда они пригодны для экрана.
- Роль презентации — помочь ребёнку видеть, слушать учителя, запоминать и замечать главное. **Не перегружать** экран мелким текстом и эффектами.

## 2. Рабочий процесс

1. Сверить, что плакат уже имеет **TEXT LOCKED / MASTER LOCKED**, а проверка 1–6 выполнена.
2. Составить **SCREEN PLAN**: каждому экрану — конкретные фразы и иллюстрации из MASTER; ни один новый факт не рождается при адаптации.
3. Утвердить композицию и последовательность: сюжетная логика плаката, ритм раскрытия, размер текста, визуальные акценты.
4. Использовать только утверждённые картинки или новые интерпретации **уже подтверждённых объектов**, не меняя фактического смысла. Художественная цельность выше декоративных «наклеек».
5. Реализовать **управляемое раскрытие по нажатию** (учитель выбирает темп), а не автоматическую смену учебных экранов.
6. Провести **проверку 1–6**, обязательную парную сверку презентации с MASTER и тестирование управления/дисплеев.
7. После приёмки владельцем зафиксировать **PRESENTATION MASTER LOCKED**. Дальше — только точечные согласованные правки; принятый состав экранов, текст, рисунки и начало не переделывать «заодно».

**Число экранов зависит от содержания.** Одиннадцать — утверждённое количество **для November**, а не универсальный норматив для всех будущих тем.

## 3. Обязательная интерактивность

- Каждый педагогический шаг раскрывается **по нажатию/тапу**; текст появляется порциями в удобном темпе.
- Очевидные **Edasi / Tagasi** (или их понятные аналоги); поддерживать возвращение к предыдущему шагу и перезапуск.
- Для компьютера и интерактивной доски — работа мышью и клавиатурой; для телефона — крупные доступные зоны нажатия и адаптивная компоновка.
- Если есть вступительный мультфильм, он не блокирует урок: **«Jäta vahele» / пропуск**, затем начало учебной части. Повторный просмотр — через явный возврат к началу.
- Режим уменьшенной анимации (**prefers-reduced-motion**) должен сохранять смысл и позволять начать урок без ожидания. Анимация не заслоняет текст.
- Полноэкранный просмотр для доски; разборчивость на смартфоне и при показе на большом экране. Смысл должен быть понятен без звука.
- Не допускать зацикленных эффектов, мешающих чтению, скачков элементов, обрезанных иллюстраций, мелких подписей и неочевидных переходов.

## 4. Пролог / мультфильм: правило и November reference

Пролог — **не двенадцатый учебный экран** и не место для новой справочной информации. Он создаёт атмосферу из проверенных образов темы; его можно пропустить.

**Утверждённый образец November 2026:** снегирь на рябине, иней, редкий спокойный снег, надпись **November**, подзаголовок **Talvekuu ja hingekuu**; длительность около **10 секунд**, затем прежняя презентация с **11 экранами**. Кнопка **Jäta vahele →** пропускает вступление; **Algusesse ↺** позволяет увидеть его снова. В ноябрьском релизе пролог **добавлен перед** утверждённой презентацией; не считать это поводом переписывать её экраны.

Для новых тем мультфильм **не является обязательным**; если он используется, его кадры, стиль и надписи проходят ту же проверку и согласование, что и другие изображения.

## 6. Проверка и запрет регрессий

**Сначала проверка 1–6**, та же, что для плаката: грамматика, филология, факты, методика, дизайн EDUKASS, критический конкурент. Она не заменяет обязательную **построчную сверку PRESENTATION ↔ TEXT MASTER**.

Далее тестируются: первый запуск, пролог, пропуск, каждый учебный экран, раскрытие по шагам, назад, перезапуск, полноэкранный режим, клавиатура, телефон, доска, уменьшенное движение и отсутствие ошибок загрузки. Итоговый визуал проверяется **в браузере**, а не только по исходному HTML или успешной сборке. Список и отчёт: **docs/POSTER_PRESENTATION_QA_CHECKLIST_RU.md**.

**LOCKED означает LOCKED.** Впоследствии нельзя «заодно» изменить иллюстрацию, заменить текст, добавить мультфильм или передвинуть экран, который уже принят. Только точечная правка по отдельному решению владельца.
