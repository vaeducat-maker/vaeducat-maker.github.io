# Обязательная проверка адаптивности EDUKASS

Перед выпуском нового ZIP проверять минимум:

- телефон 390×844;
- телефон 412×915;
- планшет 768×1024;
- ноутбук 1366×768;
- компьютер 1440×900.

На каждом размере открыть:

1. карту миссий;
2. миссию с вариантами ответа;
3. миссию с цифровой клавиатурой;
4. таблицу умножения;
5. экран результата;
6. шапку сайта.

Правило: утверждённая телефонная версия является базовой. Любые изменения для компьютера должны находиться только внутри `@media (min-width: 1101px)` либо использовать отдельный desktop-ресурс.
