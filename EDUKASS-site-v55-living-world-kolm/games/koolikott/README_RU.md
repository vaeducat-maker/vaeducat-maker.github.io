# Koolikoti memomäng — прототип

Игра уже встроена в эту версию сайта.

## Где находится
- `games/koolikott/index.html` — страница игры
- `games/koolikott/game.css` — оформление
- `games/koolikott/game.js` — игровая логика
- `games/koolikott/assets/` — отдельные изображения предметов

## Что умеет
- пары «картинка + эстонское слово»;
- 6 или 10 пар;
- адаптация под телефон и компьютер;
- переворот карточек;
- звуки правильного и неправильного ответа;
- таймер, число ходов, лучший результат в браузере;
- режим «Õpi sõnu»;
- финальное поздравление и конфетти;
- ссылка на словарный плакат.

Для локальной проверки откройте корневой `index.html`, затем нажмите `Mängi kohe`.
На GitHub Pages игра будет доступна по адресу `/games/koolikott/`.
