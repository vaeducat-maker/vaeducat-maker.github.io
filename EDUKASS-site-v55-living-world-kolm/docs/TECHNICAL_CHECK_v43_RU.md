1. загрузка старого прогресса с открытой миссией 16;

3. открытие объяснения ×3;
4. запуск миссии 16 с четырьмя вариантами ответа;
5. общий экран четырёх объяснений и блокировка ещё не открытого ÷3;

   открытое хранилище и найденный фрагмент карты.
