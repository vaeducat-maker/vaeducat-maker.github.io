# EDUKASS — серия материалов «Животные»

## Источник слов
Пользователь использует список Eesti Keele Instituut. Копия источника: `EKI_noor_animals_source.txt`.

## Принцип
Не делать один огромный словарь. Делать тематические комплекты/воркбуки, где одни и те же визуальные объекты используются в разных упражнениях.

## METSLOOMAD — текущая тема
Базовый набор:
- rebane
- hunt
- karu
- jänes
- orav
- siil
- põder
- metskits

Форматы:
1. общий плакат: единая лесная сцена + подписи;
2. карточки `pilt + sõna`;
3. карточки только с изображением;
4. карточки только со словом;
5. memo — пары одинаковых картинок;
6. `Pilt ja sõna` — сопоставление картинки и слова;
7. рабочие листы: ühenda / lõika ja kleebi / ringita / puudu olev sõna;
8. позже — цифровая игра на сайте на том же словаре.

## KODULOOMAD — следующая логичная тема
Без alpaka / laama / eesel. Базовый набор для Эстонии:
- kass
- koer
- hobune
- lehm
- lammas
- kits
- siga
- küülik

## Возможные следующие темы
- AAFRIKA LOOMAD
- LEMMIKLOOMAD
- LOOMAD MAAILMAST
- Vees ja vee ääres

## Важное правило
Серия должна быть визуально единой. Не создавать новую стилистику лисы, медведя и других животных для каждой страницы без необходимости.
