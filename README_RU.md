# KIISU MIISU — стартовый портал

Внутри уже есть:
- главная страница `index.html`;
- общий стиль `styles.css`;
- утверждённая киска в `assets/kiisu-miisu-logo.png`;
- пример страницы материала `materials/koolikott/index.html`;
- пример учебного плаката.

## Как проверить на компьютере
Откройте файл `index.html` двойным нажатием.

## Как опубликовать через GitHub Pages

1. Войдите в GitHub.
2. Нажмите `+` → `New repository`.
3. Назовите репозиторий строго так:
   `ВАШ_ЛОГИН.github.io`
4. Выберите `Public`.
5. Создайте репозиторий.
6. Нажмите `Add file` → `Upload files`.
7. Загрузите всё содержимое этой папки, сохраняя структуру каталогов.
8. Нажмите `Commit changes`.
9. Откройте `Settings` → `Pages`.
10. В `Source` выберите `Deploy from a branch`.
11. Выберите ветку `main` и папку `/ (root)`, затем `Save`.
12. Через несколько минут сайт будет доступен по адресу:
    `https://ВАШ_ЛОГИН.github.io`

## Когда выберем домен
Например, `kiisumiisu.ee`, подключим его к GitHub Pages через DNS.
После этого заменим все временные адреса в сайте и окончательно соберём QR-подпись.

## Как добавлять новый материал
Создайте папку, например:
`materials/athena/`

Внутри положите `index.html`.
Тогда адрес будет:
`https://ВАШ_ЛОГИН.github.io/materials/athena/`
а после подключения домена:
`https://kiisumiisu.ee/materials/athena/`

Позже можно сделать ещё короче:
`https://kiisumiisu.ee/athena`
